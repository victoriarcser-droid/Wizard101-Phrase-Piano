# Wizard101-Phrase-Piano
A browser-based version of the in-game Wizard101 piano for learning without opening the game, and transcribing into simplified sheet music to share online.

Created by Victoria SwiftStone

========================

TUTORIAL

Open the program and play whatever you want using the same shortcuts (and mouse) as in-game! Additionally, I added some rolling notes (visual), and a sustain option for extra fun.

The rolling notes should be blue to clarify regular note-playing mode.

Press "Record" to start recording. The rolling notes should change to red for clarity. →Press the button again (or any other button) to stop recording.

Press "Play" to playback whatever you recorded. The rolling notes should change to green for clarity. →Press "StopAll" to stop all playback.

Press "Stop All" to stop everything.

Press "'Sheet Music' Export" to export a text file of what you recorded as a simplified page of music split up into phrases based on timing. This may not be exactly correct, so double check it!

Press "Set Save Folder" to set a save folder for all subsequent text file exports. By default, clicking the "'Sheet Music' Export" button the first time in a session will prompt you to select a save folder. The "Set Save Folder" can be pressed after to pick a new save location, in case you change your mind.

It will prompt you to select a folder the first time every session (aka when you open it, close it, and open it again=that second open is a new session). Subsequently, the export should just happen automatically.

After pressing export, you will be prompted to select a name which you can type or you can just leave blank for a default title. You can press "Export"/EnterKey to download, and "Cancel"/EscapeKey to cancel.

Press "Wizard101 Forums Music Library" to bring you to a Wizard101 forum page with lots of song written for this piano format.

Press "Keybinds/MusicNotes" to toggle between showing the keybinds on the keys or the note names on the keys.

Press Spacebar Key to toggle sustain (no holding required)
